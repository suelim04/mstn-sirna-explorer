Reporter source and interpretation

The analysis used the corrected publisher Supplementary Table 3 from Huesken et al. (2005). The 2005 corrigendum states that the original last column contained predictions rather than experimental results; the publisher replaced it. The corrected table has 2,431 reagent-level averaged records.

Published normalized inhibitory activity is a linearly rescaled reporter endpoint: the positive control is 0.900 and the negative control 0.354. Higher values mean more normalized inhibition. These numbers are not literal fractions knocked down, and values above one must not be clipped. A contrast in these units is not percent knockdown.

The 2006 correction describes historical transfection and variability filtering followed by reagent-level averaging; it does not provide the raw replicate measurements. Those source quality controls were not new exclusions in this project.

The assay used an eYFP–cDNA fusion reporter context with an eCFP reference in H1299 cells. It does not establish endogenous MSTN activity. Published complete guides contain nineteen RNA bases plus variable deoxy overhangs; only the derived 19-base core was used for composition classification. The published chemistry was not rewritten to match the project's UU-overhang architecture.

The final linked analysis contains 30 species–gene labels, with two Mmp7 inserts retained as one gene. Source insert counts, mRNA labels and biological-gene counts are different counting units. Gene-family dependence and possible rule-development overlap remain unresolved limitations.
